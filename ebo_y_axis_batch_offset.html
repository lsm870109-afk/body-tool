NBA Live EBO Y축 일괄 보정 도구

여러 EBO 파일의 모든 정점 Y좌표에 동일한 값을 더하거나 뺍니다. 기본값 -1.45는 기존 Y에서 1.45를 빼는 뜻입니다. X/Z 좌표, 법선, 본 및 메시 연결 데이터는 수정하지 않습니다.

1. 파일 선택

아직 파일을 선택하지 않았습니다.

2. Y축 보정값

예: 6.93 → 5.48

양수는 위쪽(+Y), 음수는 아래쪽(-Y) 이동입니다. 이 값은 각 정점의 Y좌표에 동일하게 적용됩니다.

3. 일괄 변환

EBO 파일을 선택하세요.
변환 결과가 여기에 표시됩니다.

안전장치: 원본 파일은 브라우저에서 읽기만 하며 덮어쓰지 않습니다. 변환 결과는 ZIP 파일 하나로 내려받습니다. 변환 후 게임에서 확인해 주세요. 파일 구조가 지원 형식과 다르면 해당 파일은 건너뛰고 오류를 표시합니다.
