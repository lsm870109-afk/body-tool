NBA Live EBO 머리 위치 이동 도구

기준 얼굴 파일 없이 머리 EBO 하나만 불러와 X/Y/Z 위치를 이동합니다. 정점의 위치와 바운딩 정보만 갱신하며, 본·메시 연결·기타 데이터는 그대로 보존합니다.

1. 머리 EBO 파일

EBO 파일을 선택하세요.
아직 파일을 불러오지 않았습니다.

2. 좌표축 변환

새 게임 X/Y/Z축에 원본의 어느 축을 연결할지 선택합니다. 기본값은 원본 축 그대로입니다. 축을 바꾸거나 방향을 뒤집으면 정점과 법선 방향도 함께 변환됩니다.

주의: 축 변환은 머리 메시의 실제 방향 자체를 바꾸는 기능입니다. 기본값을 유지하면 기존 동작과 동일합니다.

3. 이동할 위치 입력

양수(+)는 해당 축의 증가 방향, 음수(-)는 반대 방향입니다. 예: X +0.2 / Y -0.1 / Z +0.5

4. 이동 결과

파일을 불러온 뒤 이동량을 입력하세요.

원본 파일은 덮어쓰지 않습니다. 저장 결과는 파일명 뒤에 _moved가 붙습니다. 게임에서 확인 후 위치가 부족하거나 지나치면 이동량을 조절해 다시 원본에서 변환하세요.
